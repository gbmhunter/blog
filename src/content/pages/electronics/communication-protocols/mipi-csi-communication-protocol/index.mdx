<WarningIsNotes />

The CSI communication protocol defines an physical, electrical and logical interface between a camera and host processor. The protocol defines OSI layers 1 (physical) through 7 (application). The CSI communication protocol is commonly used between the cameras in the smart phones and the main processor, in VR headsets, drones, and non-camera related sensing applications (such as mmWave sensors).

The specification documents of the MIPI communication protocol are only available to paying members of the MIPI Alliance[^mipi-csi-3-specs]. The official MIPI site is at [https://www.mipi.org/](https://www.mipi.org/).

MIPI also defines the MIPI DSI (Display Serial Interface) protocol, which is similar but different in that it used to connect processors to displays instead of cameras.[^spinel-mipi-csi-vs-mipi-dsi]

## Versions

### MIPI CSI-1

The MIPI CSI-1 specification was released in 2004. It is the camera _serial_ interface -- a camera _parallel_ interface was released at the same time.[^mipi-current-specifications]

It was quickly superseded by the MIPI CSI-2 specification which was released in 2005.

### MIPI CSI-2

The MIPI CSI-2 v1.0 specification was released in 2005. It is still being updated, with the v4.2 release in Dec 2025. It uses either D-PHY or C-PHY for the physical layer.

Below is a table summarizing the major versions of the MIPI CSI-2 specification:

| Version | Release Date | Comments |
|---------|--------------|---------|
| v1.0    | 2005   | Initial release. |
| v2.0    | Apr 2017 | Added support for RAW-16 and RAW-20 colour depth. Increased the number of virtual channels from 4 to 32. Introduced latency reduction and transport efficiency (LRTE). Added differential pulse-code modulation (DPCM) compression. Added scrambling to lower power spectral density.[^spinel-mipi-csi-vs-mipi-dsi] |
| v3.0    | Sep 2019 | Added Unified Serial Link (USL), Smart Region of Interest (SROI), End-of-Transmission Short Packet (EoTp) and RAW-24 colour depth. |
| v4.2    | Dec 2025 | |

### D-PHY vs C-PHY

D-PHY uses differential signalling and is the most common PHY. Vendors produce D-PHY IP with speeds of up to 6.5 Gbps per lane, and with a total of 4 lanes this gives a total bandwidth of 26 Gbps.[^arasan-mipi-c-phy-d-phy-combo-ip]

C-PHY uses 3 phase encoding in where each lane has three wires. Vendors produce C-PHY IP with speeds of up to 6 Gsps (giga-**symbols** per second) per trio. Each symbol encodes ≈2.28 bits, so gives an effective bit rate of 13.68 Gbps (giga-**bits** per second) per lane. There are up to three lanes, so the total bandwidth of ≈41 Gbps.[^arasan-mipi-c-phy-d-phy-combo-ip]

### MIPI CSI-3

MIPI CSI-3 has never been widely adopted, and CSI-2 still remains the most common MIPI camera interface.

> A basic CSI-3 v1.1 link configuration using four forward lanes and one reverse lane (10 total wires) can support up to 14.88 Gbps (usable bit rate, including 8B10B and UniPro overhead) in the forward direction and typically supports 1 Mbps or more in the reverse direction[^mipi-csi-3-specs].

## Physical Layers

The MIPI CSI-2 v1.0 protocol can use either D-PHY or C-PHY as the physical layer. Both D-PHY and C-PHY are also standards set by the MIPI Alliance.
